# Глоссарий казахской локализации (RU → KK)

Обязательная терминология для `docs/localization/public-strings.csv` и будущих казахских текстов
сайта. Утверждено владельцем 2026-09-21. Термины, помеченные «из CSV», — устоявшиеся формы,
которые уже используются в проверенных владельцем строках; источник указан в скобках.

Соблюдение главного правила (стеллаж ≠ сөре) проверяется тестом
`tests/integration/localization-inventory.test.ts` («rack vs shelf terminology»).

## 1. Главное правило: стеллаж ≠ полка

В конфигураторе есть и стеллаж целиком, и отдельные полки, поэтому эти два понятия **никогда не
смешиваются**.

| Русский | Казахский | Значение |
| --- | --- | --- |
| стеллаж, стеллажа, стеллажу, стеллажом… | **стеллаж** с казахскими окончаниями | весь стеллаж (изделие, конструкция) |
| стеллажи, стеллажей… | **стеллаждар** с окончаниями | несколько стеллажей / стеллажи как товар |
| стеллажная система | **стеллаж жүйесі** | |
| полка, полку, полкой… | **сөре** с окончаниями | ТОЛЬКО одна полка |
| полки, полок, полками… | **сөрелер** с окончаниями | ТОЛЬКО полки |

**«сөре» означает только полку.** Им нельзя переводить стеллаж, стеллажи, стеллажную систему
или конструкцию целиком — ни в одной форме (сөре, сөрелер, сөрені, сөренің, сөрелері,
сөре жүйесі, сөрелі жүйе…).

## 3. Открытые вопросы для владельца

- **«тірек» сейчас означает и стойку (CF-093), и опору (CF-043, CF-098, CF-099).** В составе
  комплекта это разные детали. Нужно решить, оставить одно слово или развести их (например,
  «тірек» для стойки и другое слово для опоры). Без решения владельца не меняется.
- **«сборка»** переводится двумя словами: «жинау» (подписи и услуга) и «құрастыру» (описательные
  тексты). Если нужен один вариант, его выбирает владелец.
